## Phase Goal

**As a** trader opening FinAlly, **I want to** see live simulated prices streaming into a dark terminal-style watchlist at http://localhost:8000, **so that** I can watch the market move in real time from a single origin.

<objective>
Walking skeleton, slice 2 of 2: put a browser on the stream. After this plan, a user opens the FastAPI server root and sees a dark page with 10 ticker rows whose prices update live from `/api/stream/prices`, plus a connection-status indicator, all served from one origin by FastAPI from the Next.js static export.

Purpose: Completes the end-to-end skeleton (Next.js export -> FastAPI static mount -> EventSource -> SSE -> cache -> simulator) that every later slice builds on.
Output: `frontend/` Next.js 16.4 + React 19.3 + Tailwind 4.3 + TypeScript 5.9 project with lint/typecheck/build scripts, theme tokens, the `usePriceStream` hook and a minimal live `Terminal` component.
</objective>
