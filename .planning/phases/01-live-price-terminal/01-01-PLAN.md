## Phase Goal

**As a** trader opening FinAlly, **I want to** see live simulated prices streaming into a dark terminal-style watchlist at http://localhost:8000, **so that** I can watch the market move in real time from a single origin.

<objective>
Walking skeleton, slice 1 of 2: the backend price stream. After this plan, an API consumer can `curl` a running FastAPI server and watch simulated GBM prices for the 10 default tickers stream over SSE every ~500ms, read from a shared in-memory price cache written by one background task, plus a health endpoint and a static mount ready for the frontend export.

Purpose: Proves the backend half of the end-to-end path (simulator -> cache -> SSE -> HTTP) with real data, so plan 01-02 can put a browser on the other end.
Output: `backend/` uv project, `app/market/` (models, cache, seed prices, simulator, source), `app/api/` (health, stream), `app/main.py`, pytest suite for cache, stream generator, health and basic simulator output.
</objective>
