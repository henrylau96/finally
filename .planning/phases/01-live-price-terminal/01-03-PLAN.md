## Phase Goal

**As a** trader opening FinAlly, **I want to** see live simulated prices streaming into a dark terminal-style watchlist at http://localhost:8000, **so that** I can watch the market move in real time from a single origin.

<objective>
Make the streamed market believable and swappable. After this plan, the prices the user already sees move like a real market: tech names move together, the finance pair moves together, and occasional 2-5% jumps add drama, all from realistic seed prices. The simulator sits behind the abstract `MarketDataSource` interface and a factory so the Massive client (Phase 5, MKT-06) plugs in without touching the cache or SSE.

Purpose: Delivers MKT-01, MKT-03, MKT-04, MKT-05 and completes MKT-02/MKT-08/TEST-01 with the full backend market-data test suite.
Output: Correlated, shock-capable `GBMSimulator` with add/remove ticker; `MarketDataSource` ABC; `create_market_data_source` factory wired into `main.py`; tests `test_simulator.py` (extended), `test_interface.py`, `test_source.py`.
</objective>
