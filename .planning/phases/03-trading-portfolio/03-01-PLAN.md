## Phase Goal

**As a** trader using the terminal, **I want to** buy and sell shares at market, **so that** I can watch my portfolio value, positions and P&L update live.

<objective>
Vertical slice 1: real money logic end to end. A trade POST runs one atomic SQLite transaction (cash, position upsert/delete, trade log), `GET /api/portfolio` reports holdings, and the browser header shows the real cash balance and a live total value from SSE prices.

Purpose: Every later slice (trade bar, positions, heatmap, P&L, Phase 4 AI trades) builds on this engine. The header is the first visible proof.
Output: app/portfolio.py, app/api/schemas.py, app/api/portfolio.py, lifespan lock, backend tests, frontend portfolio lib + hook, live Header, E2E helper wait.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/curl -> POST /api/portfolio/trade | untrusted JSON moves simulated money |
| request handler -> SQLite | concurrent writers (trades, watchlist, later snapshots) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | TradeRequest.quantity | mitigate | `Quantity`: strict float (no bool/str), gt=0 (no negative qty minting cash), le=1_000_000, allow_inf_nan=False, 4 dp with tolerance then round; 422 matrix test |
| T-03-02 | Tampering | TradeRequest.ticker/side | mitigate | `Ticker` str-only regex `[A-Z]{1,5}`; `side: Literal["buy","sell"]`; parameterized SQL only (grep gate) |
| T-03-03 | Tampering | concurrent double-spend | mitigate | lifespan `app.state.trade_lock` around price read + execute_trade, plus `BEGIN IMMEDIATE`; test_concurrent_buys expects exactly one 200 |
| T-03-04 | Tampering | partial writes on failure | mitigate | validate before any write inside one transaction; rollback on exception; tests assert cash/positions/trades unchanged after 400 |
| T-03-05 | Information disclosure | 400 detail | accept | detail only echoes the user's own cash and holdings in a single-user local app |
| T-03-06 | Denial of service | verification servers | mitigate | scratch mktemp DB_PATH, port 8014, stop by recorded PID; never `pkill -f uvicorn` |
</threat_model>
