frontend/src/lib/useHistory.ts ("use client"): export `function useHistory(ticker: string): ChartPoint[]`. State holds `{ ticker: string; points: ChartPoint[] }` (initial `{ ticker: "", points: EMPTY }` with a module-level `const EMPTY: ChartPoint[] = []`). Effect on `[ticker]`: if ticker is "" do nothing; otherwise `fetch("/api/history/" + ticker)`, parse JSON when `res.ok`, and set state `{ ticker, points }` unless the effect was cleaned up (a `cancelled` flag set in the cleanup, to drop responses for a ticker the user already left). Network or non-ok responses leave state unchanged (chart falls back to the stream). Return `state.ticker === ticker ? state.points : EMPTY` so a newly selected ticker never shows the previous ticker's history and the identity is stable while loading. Keep it under ~30 lines; no retries or polling (daily bars, backend caches per day).
